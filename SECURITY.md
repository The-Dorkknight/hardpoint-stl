# Security

Hardpoint STL reads files you give it and writes files you choose; it has no network code.
If you find a security problem (for example a crafted file that crashes or misleads a reader),
please report it **privately** through GitHub: *Security → Report a vulnerability* on this
repository. Please don't open a public issue for it.
This is a work-in-progress, as-is project with no warranty; fixes are best-effort.
